# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest `0.3.x` release line | Yes |
| Earlier release lines | No |

## Reporting a vulnerability

Please report vulnerabilities through this repository's GitHub private
vulnerability reporting flow: open the repository's **Security** tab and choose
**Report a vulnerability**. This creates a private GitHub Security Advisory for
maintainers to review.

Do not report vulnerabilities in public issues. Do not paste secrets, AI prompts
containing private source, vault contents, credentials, private keys, tokens, or
unredacted local paths into public issues or discussions.

In a private report, provide a concise description, affected version, safe
reproduction steps, impact, and any suggested mitigation. Redact unnecessary
personal or proprietary data. Maintainers will acknowledge and investigate
reports privately and coordinate disclosure after a fix is available.
