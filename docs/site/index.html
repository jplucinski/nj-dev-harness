Scope

Global navigation. Project commands stay local.

Dev Harness handles repository navigation, worktrees, AI context, and notes. Each project defines its own build, test, run, deploy, and release commands.

01 / Find

Find a repository

Search recent and modified work, show the current context, or return to the repository root.

dirty why gr

02 / Do

Create a worktree

Create timestamped worktrees, prepare a handoff, or invoke the configured AI command.

gtask wt -- feature/retry handoff --copy gtask review

03 / Remember

Write notes and TODOs

Find the highest-priority TODO or append the current status to an Obsidian Daily note.

focus p0 standup standup --day

AI context

Select files before review.

gtask review requires an interactive terminal and an explicit fzf selection. A non-interactive run stops before invoking AI.

default
gtask review

Choose exactly which changed files enter the prompt.

--all
gtask review -- --all

Send every changed file that survives the sensitive-path policy.

Common `.env`, private-key, keystore, `.ssh`, `credentials*`, and `secrets*` paths are centrally excluded. Always inspect scope before using an external AI service.

Install

Requirements and installer

Install Bash, Task, Git, fzf, rg, and grepai, then run the installer from a release archive or source checkout.

macOS / Git Bash
./install.sh --configure-shell
Windows PowerShell
powershell -ExecutionPolicy Bypass \
  -File .\install.ps1 --configure-shell
then gtask doctor → gtask → resume
